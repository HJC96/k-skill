# 종교시설 찾기 가이드

## 이 기능으로 할 수 있는 일

- 동네·역명·랜드마크 기준 근처 종교시설 거리순 조회
- 교회(기본), 성당, 사찰을 같은 경로로 조회
- 시설 이름으로 직접 검색해 여러 지점 구분
- 도로명 주소, 기준점으로부터의 직선거리, 전화번호, 홈페이지, 카카오맵 장소 링크 정리

사용자 API 키가 필요 없습니다. 공개 표면만 사용하므로 `k-skill-proxy`도 거치지 않습니다.

## 가장 먼저 할 일

이 기능은 **위치를 먼저 확인한 뒤** 실행합니다.

권장 질문 예시:

```text
어느 동네나 역 근처에서 찾을까요? (예: 강남역, 성수동)
```

위치도 이름도 없으면 임의로 좁히지 말고 사용자에게 물어봅니다.

## 입력값

- 동네·상권: `성수동`, `광화문`, `해운대`
- 역명·랜드마크: `강남역`, `홍대입구역`, `코엑스`
- 시설 이름: `--name 온누리교회`

옵션:

| 옵션 | 설명 |
| --- | --- |
| `--type` | `교회`(기본) / `성당` / `절` / `사찰` / `전체` |
| `--radius` | 기준점으로부터 최대 거리(m) |
| `--limit` | 표시 개수 (기본 5, 최대 15). upstream이 한 번에 최대 15건만 반환합니다 |
| `--json` | JSON 출력 |

좌표(`위도,경도`) 입력은 지원하지 않습니다. helper가 명시적으로 거부하고 동네·역명을 요구합니다.

## 공식 표면

- 카카오맵 모바일 검색: `https://m.map.kakao.com/actions/searchView`
- 카카오맵 장소 패널 JSON: `https://place-api.map.kakao.com/places/panel3/<confirmId>`

두 요청 모두 브라우저 `User-Agent`가 필요합니다. 없으면 403이 떨어집니다. panel 요청에는
`appVersion`, `pf`, `Origin`, `Referer` 헤더를 함께 보냅니다. 같은 표면을
[근처 공중화장실 찾기](public-restroom-nearby.md)가 이미 사용하고 있습니다.

참고 출처(주 경로로는 쓰지 않음):

- 서울특별시 종로구 교회 현황: `https://www.data.go.kr/data/15117640/fileData.do`
- 서울특별시 관악구 종교시설 현황: `https://www.data.go.kr/data/15117616/fileData.do`

지자체 공공데이터는 구 단위로만 공개되어 전국 표준데이터가 없습니다. 그래서 전국 커버리지가
필요한 이 기능의 주 경로로는 쓰지 않고 참고로만 둡니다.

## 종교시설 판별 기준

카카오 장소 분류에는 `종교` 노드가 실제로 존재합니다.

```
교회 → name1: 문화,예술 / name2: 종교 / name3: 기독교 / name4: 교회
성당 → name1: 문화,예술 / name2: 종교 / name3: 천주교 / name4: 성당
```

`category.name2 == "종교"`로 필터하므로 이름에 "교회"가 들어간 카페·서점·출판사가
결과에 섞이지 않습니다. 같은 필터 하나로 성당·사찰까지 커버됩니다.

## 기본 흐름

1. 사용자에게 위치를 먼저 묻습니다.
2. 위치 문자열로 검색해 기준점 후보를 고릅니다. 검색어와 이름이 가까운 장소를 우선합니다.
3. `<위치> <종류>`로 다시 검색해 장소 id를 모읍니다.
4. 각 장소의 패널 JSON을 조회해 좌표·주소·연락처를 확보합니다.
5. `name2 == 종교`가 아닌 후보를 버립니다.
6. upstream이 주는 거리 값을 쓰지 않고 기준점과 haversine으로 직접 거리를 계산해 정렬합니다.
7. 가장 가까운 3~5개만 짧게 응답합니다.

## 실행 예시

```bash
npx -y @nomadamas/k-skill@0 exec religious-facility-search scripts/religious_facility_search.py -- "강남역" --limit 5
npx -y @nomadamas/k-skill@0 exec religious-facility-search scripts/religious_facility_search.py -- "명동" --type 성당
npx -y @nomadamas/k-skill@0 exec religious-facility-search scripts/religious_facility_search.py -- "성수동" --radius 600
npx -y @nomadamas/k-skill@0 exec religious-facility-search scripts/religious_facility_search.py -- --name "온누리교회"
```

## 출력

```
기준 위치: 강남역사거리 (37.49795, 127.02764)
검색어: "강남역 교회" · 후보 15건 중 종교시설 15건 (가까운 3건 표시)

1. 강남성서침례교회  (교회 · 기독교)
   서울 서초구 강남대로55길 9-11 9층 (서초동)
   약 320m
   https://www.gnbbc.or.kr/
   지도 https://place.map.kakao.com/85095074

예배·미사·법회 시간은 이 데이터에 없다. 각 홈페이지나 전화로 확인할 것.
```

`--json`은 `query`, `anchor`, `scanned`(후보 수), `matched`(종교시설 수), `items[]` 구조로 출력합니다.

## 한계

- **예배·미사·법회 시간은 제공하지 않습니다.** upstream `open_hours`가 비어 있습니다.
  홈페이지나 전화로 안내하고 추정하지 않습니다.
- **교단·종파 소속 정보가 없습니다.** 이름에서 추론하면 부정확하므로 하지 않습니다.
- **공식 문서화된 API가 아닙니다.** 모바일 웹 표면이므로 upstream 구조가 바뀌면 결과가
  0건이 될 수 있습니다.
- 장소당 패널 조회가 1회씩 붙습니다. 한 번의 검색으로 최대 15곳까지만 확인할 수 있습니다.

## 실패 모드

| 상황 | 대응 |
| --- | --- |
| 검색 결과 없음 | 상위 행정구역으로 넓혀 재시도 |
| 지정 종류 0건 | `--type 전체`로 넓히거나, `--radius`를 걸었다면 해제 |
| HTTP 403 | `User-Agent` 누락. helper 경유로 호출 |
| HTTP 5xx·타임아웃 | 재시도 후 계속 실패하면 그대로 보고 |
| 기준점 해석 실패 | 거리 없이 결과 목록만 제공 |
| upstream 구조 변경 | 결과 0건. 지어내지 않고 실패로 보고 |

## 다루지 않는 것

- 종교나 교단의 우열을 평가하거나 이단 여부를 판별하지 않습니다.
- 특정 시설이나 교단을 권유하지 않습니다. 거리와 공개 정보만 근거로 나열합니다.
- 등록·연락·방문 예약 같은 액션을 대신 수행하지 않습니다.
- 사용자가 제공한 위치 텍스트만 사용하고 위치를 자동으로 알아내지 않습니다.
